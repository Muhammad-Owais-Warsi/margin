# Margin

Minimal sidebar notes for Chrome. Just write.

</div>

## Install

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. **Load unpacked** → select this folder

## Use

- `Ctrl+Shift+Y` (Mac: `Cmd+Shift+Y`) — open / close the sidebar
- `+` — new note, click a number to switch, right-click it to delete
- `E` — download backup (`margin-backup-*.json`)
- `L` — load a backup (only Margin backup files are accepted)

Notes autosave locally in your browser. Nothing leaves your machine.
